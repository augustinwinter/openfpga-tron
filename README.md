# Tron — openFPGA core for Analogue Pocket

**Core:** Tron · **Version:** 0.2.0 (V02) · **Hardware:** Bally Midway MCR-II (1982)  
**Pocket port and controller adaptation:** August and Doctor Lucy (ChatGPT)

This is an independent FPGA preservation adaptation of the original arcade game **Tron** for the Analogue Pocket's openFPGA framework. The adaptation integrates a dual-stick layout for an external controller while preserving a fully usable handheld control scheme.

## Status

- Tron V02 has been reported as **working on physical Analogue Pocket hardware both docked and undocked**.
- 18 input-mapper simulation checks passed. Full Quartus synthesis passed, with positive reported timing slack. Timing constraint coverage remains incomplete in the inherited build.
- The debugging logger was removed. The ROM is selected automatically by filename, without navigating to a Game Definition subfolder.
- External rear paddles P1/P2 on an 8BitDo Pro 2 were **not** confirmed working even when mapped to A. They are not supported as separate openFPGA keys in this build.

## Core identity

The original machine is **Midway MCR-II** arcade hardware, not a modern software engine. The core's internal platform ID is `midway_mcr2`, while the Pocket-facing menu label is `Tron`. The platform banner is a 521×165 pixel source converted to Analogue's rotated 16-bit monochrome `.bin` format.

## Installation

The **Pocket installation archive** has `Cores/`, `Platforms/`, and `Assets/` directly at its root. See [INSTALLATION.md](INSTALLATION.md).

**Do not extract a repository/source ZIP onto the Pocket SD card.** Only use the `Tron-V02-0.2.0-PRIVATE-Pocket-install.zip` installer for a personal installation. Pocket Sync and other updaters may require separate catalog registration; a valid installation ZIP does not guarantee inclusion in their updater catalogs.
